# 0010. 클라우드는 Azure, 오케스트레이션은 AKS

상태: 채택 (2026-11-06, 기획서 v0.6)

## 맥락

클라우드 트랙 요건은 퍼블릭 클라우드 배포·운영, 컨테이너 오케스트레이션으로 운영·배포 자동화, Terraform으로 인프라 정의다(기획서 3절). 어느 클라우드든 요건은 채울 수 있다. 제약은 돈이다. 팀은 학생이고 결제 수단 없이 쓸 수 있는 크레딧이 필요하며, 시연 한 번을 위한 클러스터를 3~4주 운영한다.

## 결정

Azure를 쓰고, 쿠버네티스는 관리형 AKS로 한다.

- **Azure for Students**: 신용카드 없이 $100 크레딧을 받는다. 팀원 4명이 각자 받을 수 있어, 한 구독의 크레딧이 떨어지면 다른 팀원 구독에 클러스터를 다시 만든다(기획서 리스크 표). DB를 클러스터 밖에 둔 이유(0005)와 맞물린다.
- **AKS Free tier**: 관리 플레인 비용이 없어 크레딧은 대부분 노드 비용에 쓰인다. 그 밖의 과금 항목은 Standard Load Balancer, 공인 IP, 노드 OS 디스크, Terraform 상태용 스토리지다(0008).
- 다른 클라우드는 비교하지 않았다. 결제 수단 없이 받을 수 있는 크레딧이 팀에게는 Azure for Students뿐이었다는 점이 기준이다.
- Terraform은 트랙 요건이라 선택이 아니다. Azure 자체 도구(Bicep, ARM)는 요건상 제외된다.

## 결과

- 결제 수단 없이 시작하고, 크레딧 소진 시 팀원 구독으로 옮기는 계획이 성립한다.
- 감수할 것: 학생 구독은 쿼터가 작다(koreacentral 리전 6 vCPU, 0008). 노드 크기와 수가 여기 묶인다.
- 감수할 것: 크레딧이 소진되면 과금이 아니라 **구독 비활성화**다. 시연 전에 꺼질 위험이 있어 클러스터를 쓰지 않을 때 `az aks stop`으로 내리고, 예산 알림을 건다.
- 감수할 것: 구독을 옮기면 클러스터를 처음부터 다시 만든다. Terraform `apply`로 재현되는 것이 전제다(T2).
- 감수할 것: 노드 OS 자동 업그레이드, NetworkPolicy 기본값 없음 같은 AKS 기본 설정은 Terraform에서 명시해야 한다(0008).
